# Your personal LinkedIn profile

This matters more than the company page. Pages have almost no organic reach and
nobody browses them; the profile is what a prospect opens after your message,
and it is where posts actually travel. Set this up first. It needs no domain
email, so none of it is blocked.

---

## Profile photo

Use the founder photo already on the site (`public/assets/about/founder.webp`).
Crop it square, face filling roughly 60% of the frame. The same face on the
site and the profile is a small consistency that people register without
noticing.

## Background banner

`brand-kit/linkedin/cover-1128x191.png` works here too. LinkedIn personal
banners are 1584x396, so it will scale up soft. If it looks poor, use plain
black with the wordmark rather than a stretched image.

## Headline

220 characters. This follows you into every comment, every DM, every search
result, so it does more work than anything else on the profile.

**Option A, outcome first:**
```
I build websites and web apps for founders who need it done properly the first time | Fixed price, remote, senior-led | Founder at Webify
```

**Option B, service first:**
```
Websites, SaaS products and web apps, built end to end | Next.js and React | Fixed price, remote | Founder at Webify
```

Take A if you plan to post. Take B if you plan to be found in search. Do not
write "Helping businesses grow their digital presence": every third profile
says it, which makes it invisible.

## Two settings people forget

**Open to work → Providing services.** Free, and it puts you in LinkedIn's
services marketplace where buyers actually search. Pick Web Design, Web
Development, and Software Development.

**Custom URL.** Change `linkedin.com/in/navneet-prasad-8a4b2c1d` to
`linkedin.com/in/navneetprasad` or similar. It goes on every proposal you send.
